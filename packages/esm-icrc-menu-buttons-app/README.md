# @icrc/esm-icrc-menu-buttons-app

Menu buttons microfrontend for the OpenMRS SPA.

Part of [openmrs-esm-icrc](https://github.com/icrc/openmrs-esm-icrc), a monorepo of OpenMRS 3.x frontend modules maintained by the ICRC.

## Usage

This is an OpenMRS frontend module rather than a library. It is not imported into application code, it is registered with an OpenMRS distribution, which loads it at runtime.

## Development

Work from the root of the [monorepo](https://github.com/icrc/openmrs-esm-icrc) rather than this directory:

```sh
yarn install
yarn verify
yarn build
```

Versioning and publishing are documented in the [monorepo README](https://github.com/icrc/openmrs-esm-icrc#publishing).
